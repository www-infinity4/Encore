# Encore Channel

Encore is the strictly 1980s-and-1990s station in the Infinity synchronized TV network. Every viewer in Live mode sees the same feature at the same Central Time broadcast moment, with Start Over, Rewind, and Join Live controls.

The launch catalog favors recognizable adventure, fantasy, science fiction, comedy, action, and prestige movies. Only full-length YouTube sources that reported playable embedding when checked are enabled.
